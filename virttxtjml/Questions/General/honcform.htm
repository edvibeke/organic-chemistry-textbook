Lewis / Kekulé Structures

For the Lewis / Kekulé structures shown on the left, answer questions 1 through 8. For each designated condition enter appropriate letters (A to I), identifying the chosen structures, in each answer box. If no structure fits the description enter the letter X. Do not enter superfluous characters, since they will be counted as incorrect answers.

   1. Formulas that have no formal charged atoms.
2. Formulas in which nitrogen has a (+) formal charge.
3. Formulas in which nitrogen has a (–) formal charge.
4. Formulas in which oxygen has a (+) formal charge.
5. Formulas in which oxygen has a (–) formal charge.
6. Formulas in which carbon has a (+) formal charge.
7. Formulas in which carbon has a (–) formal charge.
8. Formulas having an electron deficient C, N or O.
