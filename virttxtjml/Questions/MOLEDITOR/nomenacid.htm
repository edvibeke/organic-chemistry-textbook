Nomenclature of Carboxylic Acids, Esters, Chlorides & Anhydrides

For each of the following problems, select the type of question. If you select Write Name a structure will appear in the drawing window when the Show Problem button is pressed. You should then write the IUPAC name for this compound in the text window just below the drawing window. Be careful to include all the necessary parentheses, dashes and commas in your name. Any Greek letters must be spelled (e.g. alpha). If you select Draw Structure a name will appear in the larger Information Window on the bottom left when the Show Problem button is pressed. You should then draw a formula corresponding to this name in the drawing window. Configurations should be designated by using the wedge drawing tool.
When you are finished, check your answer by pressing the Check Answer button. A response will appear in the Information Window.
The answer to a given problem will be displayed by showing its alternate form.
